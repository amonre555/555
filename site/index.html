FAQ

Questions

Does 555 cost anything?

No. 555 is free and open source (GPL-3.0), with no subscription and no paid tier.

Do I need an account?

No. Install it and press play. 555 never asks you to sign in and doesn't collect usage data.

Where does the music come from?

Song info, covers and charts come from Deezer's public API. The sound itself comes from YouTube Music, matched to the same recording (title, artist, length, skipping live and sped-up versions). Your own files play straight from disk.

Can it play my own files?

Yes: MP3, FLAC, OGG, M4A/AAC, WAV and AIFF. 555 reads tags and cover art and never touches the originals.

How do I import a Spotify playlist?

Paste the link of a public playlist (or album). 555 finds each song on Deezer and creates the playlist, no Spotify account needed.

Which languages does it speak?

English and French for now. Change it in Settings → General.

Is it safe? The app isn't signed.

Signing with Apple and Microsoft costs money each year, so the macOS and Windows installers aren't signed yet (the Android APK is signed, but isn't on the Play Store). The code is public and the builds are made by GitHub Actions from it. Updates are signed, and 555 refuses any update whose signature doesn't match.
